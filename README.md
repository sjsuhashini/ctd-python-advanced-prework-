# Country Explorer CLI

A Python command-line application that retrieves country information from the [countries.dev API](https://countries.dev/countries) and allows users to explore country data.

## Features

- View countries by region
- Find the top 10 largest countries by area
- Find the top 10 most populous countries
- Search for countries by name
- Display country details, including capital, region, population, area, and languages

## Requirements

- Python 3
- Internet connection
- Python package: `requests`

## Setup

### 1. Clone the repository

Clone this repository from GitHub and open the project folder in your terminal.
git clone [<your-github-repository-url>](https://github.com/sjsuhashini/ctd-python-advanced-prework-.git)

### 2. Create a virtual environment

```powershell
py -m venv .venv
```

### 3. Activate the virtual environment

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 5. Run the application

```powershell
python countryExplorer.py
```
